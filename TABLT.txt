1. התקן Termux על טאבלט השרת


# ב-Termux:
pkg update && pkg install nodejs
2. העתק את תיקיית server/ לטאבלט (דרך USB או git clone)

3. הפעל את השרת


cd server
npm install
node src/server.js
4. טאבלטים השופטים — מזינים http://192.168.x.x:5000 (ה-IP של טאבלט השרת ברשת)

5. אפליקציה על טאבלט השרת עצמו — מתחבר ל-http://localhost:5000 או לאותו IP

המגבלה החשובה
אפליקציית ה-Flutter שלנו מצמידה (kiosk) — לא ניתן לעבור ל-Termux.

לכן טאבלט השרת צריך לעבוד בלי הצמדה (Unlock ב-5 הקשות על העיגול), או להפעיל Termux לפני הפעלת האפליקציה.

פתרון פשוט: Termux מריץ את השרת ב-background → מפעיל את האפליקציה → האפליקציה מתחברת ל-localhost.
